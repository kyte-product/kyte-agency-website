# Local visual review exports

This directory holds generated review renders, masks, evidence screenshots and source notes. It is separate from deployed assets in `kyte-site/public/` and from runtime components. Most draft exports are intentionally untracked.

Keep source names stable while a design task is active. For a completed task, preserve its files together in a dated subfolder when all referenced paths can be updated. Do not remove older renders or publish external reference captures as website artwork. Approved release evidence belongs in `kyte-site/docs/release/<date>/` with the tested revision.

Current active art skills are indexed by `.agents/skills/README.md`; retired components are indexed in `kyte-site/backups/`.
