# Tool logo assets

## 20 October 2026: service hero color assets

- shopify-color.svg, wordpress-color.svg and claude-color.svg retain SVG paths from https://github.com/gilbarbara/logos (logos/shopify.svg, wordpress-icon.svg and claude-icon.svg). Shopify uses its original green fills; Claude uses original #D97757. WordPress uses its blue #21759B variant in place of the source dark gray fill.
- webflow-color.svg is the official blue mark from https://dhygzobemt712.cloudfront.net/Mark/Mark_Logo_Blue.svg, linked by https://brand.webflow.com/brand-assets.
- sanity-color.svg retains the existing sanity.svg paths with Sanity red #F03E2F.
- framer.svg retains the existing official black geometry. Framer's current brand reference is https://www.framer.com/brand.
- figma-color.svg is the existing multicolor asset.

Reference pages: https://www.shopify.com/brand-assets and https://wordpress.org/about/logos/. Brand names and artwork belong to their respective owners. These are local illustration assets, not publication or affiliation claims.
