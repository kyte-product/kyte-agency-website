# Kyte project skills

Stable entry points stay in individual folders. Read a skill before using its workflow.

| Folder | Purpose | Supporting folders |
| --- | --- | --- |
| `hairline-create/` | Hairline construction/reference engine | examples, build and validation scripts |
| `kyte-isometric-art/` | Kyte isometric illustration construction and review | references, scripts, assets, agents |
| `kyte-imagegen-art/` | Raster artwork prompts and review | references, agents |

Shared website UI rules, including the dot component, live in `kyte-site/docs/template-system.md` and `/design-system`. Editorial artwork guidance remains at root `skills/kyte-editorial-art/SKILL.md`.

Keep generated screenshots and review exports outside runtime source. Preserve older experiments in dated backup folders. Do not copy external reference artwork into public website assets without clearance. Existing local untracked skill references are preserved; a release stages only reviewed source files.
