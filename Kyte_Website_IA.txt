3. STRUCTURE NOTES
======================================================================

- Cluster pages (/ui-ux-design-development and /branding-marketing)
  are the dedicated landing pages and act as the parent folders for
  their services. No separate /services folder is used.
- Location pages sit at the top level so the keyword follows the
  domain directly. Link them from the footer, not the main nav.
- /industries needs its own overview page since it is a folder.
  A simple grid linking to each industry is enough.
- Case study slugs use the client name, e.g. /work/fincart.
- /design-system is an internal working page for the website build. It is
  not part of public navigation or the SEO route map and remains noindex.
  No dates or project codes.
- /graveyard/landing-page is an internal, noindex snapshot of the homepage
  before the 9 October 2026 hero redesign. Keep it outside public navigation.
- Dubai and UK location pages can be added later
  (e.g. /web-design-company-dubai) without changing anything else.
- Do not use "Framer" in nav labels or slugs (very low search volume).
  Mention it in page copy instead.
- Dropping "services" from URLs has no meaningful SEO impact. What
  matters is keeping this structure fixed once live.

4. 301 REDIRECTS
======================================================================

Order matters. Specific rules first, catch-all last.

  FROM                                   TO
  -------------------------------------  ---------------------------
  /services                              /
  /services/ui-ux-design-development     /ui-ux-design-development
  /services/branding-marketing           /branding-marketing
  /services/*                            /

- Set up in Framer: Site Settings > Redirects.
- Test each rule in an incognito window after publishing.


======================================================================
5. THINGS TO WATCH
======================================================================

1. Never link to /services anywhere: footer, sitemap or internal
   buttons. If nothing links to it, Google never treats it as a real
   page. The redirect is only a safety net for people typing it in.

2. Map the current site's URLs. Any existing kyte-agency.com page that
   changes or disappears needs its own 301 to the closest new page.
   This matters more than /services, since old URLs may already have
   rankings and backlinks.
